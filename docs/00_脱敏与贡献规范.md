# 脱敏与贡献规范

> 适用项目：校园网认证研究（开源镜像仓）
> 本文档定义贡献者的**保密红线**、**占位符规范**、**提交前自查流程**与 **PR 检查清单**。
> 原则：**开源仓库只承载方法论、结论与可复现逻辑，不承载任何可识别个人/设备/网络的原始标识。**

---

## 1. 适用范围

适用于所有提交到开源仓的：

- 文档（Markdown / 文本）
- 脚本（PowerShell / Shell / Python 等）
- 配置样例（yaml / json / 认证请求样例）
- 截图、日志摘录、测试记录表
- PR 描述、review 评论

私密材料（原始脚本、原始日志、带真实标识的记录）**一律留在本地私密目录**，不得进入版本库历史——已被推入历史的内容同样违规，需按第 7 节处理。

---

## 2. 贡献者红线（禁止清单）

以下内容**在任何形式下都禁止提交**，无论是否"看起来无害"：

| # | 类别 | 说明 |
|---|---|---|
| 1 | **真实 MAC 地址** | 任何网卡的 IEEE MAC（含冒号/连字符/点分格式）、OUI 前缀组合出的完整地址 |
| 2 | **真实 IP 地址** | 内网 IP、网关 IP、出口公网 IP、认证/门户服务器 IP、任何 `IP:端口` 组合 |
| 3 | **厂商/品牌名** | 接入服务商、认证客户端、校园网相关商业品牌及其产品名、域名（作为查杀黑名单的具体词语见 §5.2） |
| 4 | **订阅/机场信息** | 任何代理订阅 URL、机场站点名/域名、节点地址（含"测试期间退出某机场"这类提及） |
| 5 | **真实账号信息** | 用户名、密码、口令、AES/加密密钥常量、Token、会话票据、任何可登录的值 |
| 6 | **他人设备与隐私** | 他人设备的 MAC/IP、SSID、网络名、实名信息、位置信息、任何他人数据 |
| 7 | **精确测量数值** | 精确到小数位的速率/时序数值（应改为相对结论或量级区间，见 §2.1） |
| 8 | **私密路径引用** | 本机绝对路径、私密目录名/路径、内部工具链的完整路径 |

### 2.1 数据表述规则

实测数据一律脱敏表述：

- ✅ 允许："双会话总速率约为单会话的 **1.7~1.9 倍**""平台值处于**数十 Mbps 档位**""上行约为下行的 **1/5**"
- ❌ 禁止："测得 98.7 Mbps""源地址 10.x.x.x"（此处为格式示例，禁止任何真实地址本身）
- ✅ 例表、曲线图可保留（图内只出现相对倍数与量级区间，不得出现真实标识）

## 3. 占位符规范

### 3.1 格式

- 统一使用尖括号包裹的英文/数字下划线形式：`<占位符名>`；
- 同一实体在全文/全仓中使用**同一个占位符**（例如某会话的 MAC 始终是 `<MAC_A>`，不得一会儿 `<MAC_A>` 一会儿 `<mac_a>`）；
- 占位符名只表达"角色"，不携带任何真实值（`<MAC_A>` 表达"会话 A 的设备标识"，其具体值不可从文档推断）；
- 新增占位符必须先在本规范 §3.2 清单中登记（PR 检查项之一）。

### 3.2 推荐占位符清单

| 类别 | 推荐占位符 |
|---|---|
| 设备标识 | `<MAC_A>`、`<MAC_B>`、`<设备MAC>`、`<虚拟机MAC>` |
| 网络标识 | `<内网IP_A>`、`<内网IP_B>`、`<网关IP>`、`<网段CIDR>`、`<出口IP>`、`<DNS_IP>` |
| 无线标识 | `<SSID>`、`<网络名>`、`<信道>` |
| 服务器标识 | `<认证服务器IP>`、`<认证服务器域名>`、`<门户URL>`、`<NAS名称>` |
| 账号与会话 | `<账号名>`、`<用户名>`、`<密码>`、`<会话ID>`、`<并发上限>` |
| 密钥材料 | `<加密密钥>`、`<Token>`（若必须演示结构，用 `0x` + 明确标注"示例值"） |
| 测试对端 | `<测速源甲>`、`<测速源乙>`、`<对比文件URL>`、`<文件大小>`、`<文件哈希>`* |
| 服务商/厂商 | `<接入服务商>`、`<认证客户端厂商>`、`<运营商甲>` |
| 订阅相关 | `<机场名称>`、`<订阅URL>` |
| 接口与路由 | `<物理WAN接口>`、`<LAN接口>`、`<接口名>`、`<出口接口A/B>`、`<默认路由网段>`、`<探活目标IP>` |
| 代理出口 | `<节点A-名称>`、`<节点A-服务器地址>`、`<节点A-端口>`、`<节点A-密码>`、`<节点A-加密方法>`、`<节点A-接口名>`、`<混合端口>`、`<控制API地址>`、`<健康检查URL>`、`<节点源文件路径>`、`<聚合组名>`、`<境外组名>`、`<SOCKS监听地址>`、`<SOCKS端口-A/B>` |
| 服务与守护 | `<服务描述>`、`<运行用户>`、`<运行用户组>`、`<保活脚本路径>`、`<保活间隔秒>`、`<重启间隔秒>`、`<mihomo可执行文件路径>`、`<mihomo配置目录>` |

> *`<文件哈希>`：内容哈希（如 SHA256）用于完整性校验时**允许保留真实值**，因为它不标识设备或个人；若对外站无实质意义，仍建议占位。

## 4. 提交前自查（可执行）

提交前在**待提交目录**运行下列检查。两种引擎任选其一（建议 ripgrep）。

### 4.1 一键自查脚本

```bash
# 需要：ripgrep (rg)。cd 到待提交目录（如仓库根）后运行：
rg -n -i \
  -e '([0-9A-Fa-f]{2}[:-]){5}[0-9A-Fa-f]{2}' \
  -e '\b[0-9]{1,3}(\.[0-9]{1,3}){3}(:\d{1,5})?\b' \
  -e '([0-9A-Fa-f]{1,4}:){2,7}[0-9A-Fa-f]{0,4}' \
  -e 'wnet|微网|翼讯|ikuuu|订阅|航空|机场(免费|加速)?' \
  -e 'username\s*[:=]|password\s*[:=]|passwd|token\s*[:=]' \
  -e '私密|内网直连|密钥[:=]' \
  .
```

PowerShell 等价版本：

```powershell
# 在待提交目录执行
$pat = '([0-9A-Fa-f]{2}[:-]){5}[0-9A-Fa-f]{2}|\b[0-9]{1,3}(\.[0-9]{1,3}){3}(:\d{1,5})?\b|wnet|微网|ikuuu'
Get-ChildItem -Recurse -File -Force |
  Where-Object { $_.Extension -match '\.(md|ps1|sh|py|yaml|yml|json|txt|conf)$' } |
  Select-String -Pattern $pat -ErrorAction SilentlyContinue |
  ForEach-Object { "$($_.Path):$($_.LineNumber): $($_.Line)" }
```

> 提示：扫描出的命中可能来自**本文档自身**（正则模式、黑名单词条）。自查时把"docs/00_脱敏与贡献规范.md 内的模式定义"视为白名单，其余任何命中都必须人工复核。

### 4.2 模式清单详解

| # | 模式 | 正则（PCRE 风格） | 说明 |
|---|---|---|---|
| 1 | MAC 地址 | `([0-9A-Fa-f]{2}[:-]){5}[0-9A-Fa-f]{2}` | 匹配 `AA:BB:CC:DD:EE:FF` / 连字符格式 |
| 2 | MAC 点分（Cisco 风格） | `[0-9A-Fa-f]{4}\.[0-9A-Fa-f]{4}\.[0-9A-Fa-f]{4}` | 补充格式 |
| 3 | IPv4 | `\b[0-9]{1,3}(\.[0-9]{1,3}){3}\b` | 覆盖内网/公网/网关 |
| 4 | IP:端口 | `\b[0-9]{1,3}(\.[0-9]{1,3}){3}:\d{1,5}\b` | 认证/门户服务器常见形态 |
| 5 | IPv6（宽松） | `([0-9A-Fa-f]{1,4}:){2,7}[0-9A-Fa-f]{0,4}` | 命中后人工复核（避免误报时间戳） |
| 6 | 厂商名关键词 | 见 §5.2 黑名单 | 命中即违规，除非位于本规范白名单语境 |
| 7 | 账号/口令字段 | `username\s*[:=]|password\s*[:=]|passwd|token\s*[:=]` | 键名出现即提示，值必须占位 |
| 8 | 密钥常量 | `-K [0-9A-Fa-f]{16,}|key\s*=\s*[0-9A-Fa-f]{16,}` | 长 hex 常量疑似密钥 |
| 9 | 精确速率 | `\d+(\.\d+)?\s*Mbps` | 非绝对禁止，但需按 §2.1 改写 |

### 4.3 人工复核要点（机器扫不出的）

- **截图**：地址栏、表格、面板里的真实 IP/MAC/账号，必须打码或裁剪后再提交；
- **URL 查询串**：形如 `?mac=…&ip=…` 的样例，参数值必须占位；
- **日志摘录**：认证响应体里可能带用户标识 / hex 串；
- **注释与变量名**：脚本注释里顺手写下的真实值；
- **历史提交**：`git log -p` 中残留的历史真实值（见第 7 节）。

## 5. 提交前自查（黑名单词条）

### 5.1 使用方式

黑名单用于 §4.1 的 grep 引擎（`rg`/`Select-String` 均可直接消费）。命中处理规则：

- 会话身份字段（username/password/token/mac/ip）附近命中的黑名单词 → 高中危，必须替换为占位符；
- 仅作为"查杀目标"出现在本规范文档内的词条 → 白名单（本文件自身允许出现黑名单词，因为它是检查工具的一部分）。

### 5.2 项目黑名单（维护区）

> 以下为**查杀目标词条**，仅在本规范与自查脚本中出现；任何提交内容中出现即违规。

```
# —— 服务商 / 认证客户端 ——
wnet            # 接入服务商品牌
微网通联        # 客户端厂商
翼讯            # 配套客户端品牌
# —— 订阅 / 机场 ——
ikuuu          # 代理订阅服务名（大小写不敏感）
订阅URL         # 凡含 "订阅" 且指向代理服务的形态
# —— 路径 / 目录 ——
私密            # 私密材料目录名（真正路径已被省略，禁止引用）
# —— 段落示例即上述形式；新增黑名单词请追加到本区并同步 §4.1 脚本 ——
```

> 说明：词条以公司/产品公开品牌名为准做**全仓扫描**，不写具体地址类原语；真实 MAC/IP/账号不会以黑名单形式存在，而是通过正则（§4.2 #1~#8）拦截。

## 6. PR 检查清单

提交 PR 前逐条勾选（reviewer 复核时逐条核对）：

- [ ] **1. 标识扫描**：§4.1 脚本全仓运行，MAC/IP/密钥/口令类正则**零命中**（本规范文件自身除外）；
- [ ] **2. 黑名单扫描**：§5 黑名单词条零命中（本规范自身除外），未新增未登记敏感词；
- [ ] **3. 占位符合法**：所有敏感值均以 `<占位符>` 形式给出，且占位符已在 §3.2 清单登记；新增占位符已同步更新该清单；
- [ ] **4. 数据表述**：实测数据均为相对结论/量级区间（如"1.7~1.9 倍""数十 Mbps 档位"），无精确数值；
- [ ] **5. 附件安全**：截图/日志/表图中无未打码的真实标识（地址栏、面板表格、认证响应体均已检查）；
- [ ] **6. 无路径泄露**：不含本机绝对路径、私密目录路径、内部服务器地址；
- [ ] **7. 可复现性**：关键结论附方法引用（如《experiments/verify_aggregation.md》），原始数据未随 PR 提交而保存在私密侧；
- [ ] **8. 自查记录**：PR 描述中附一行自查结果（如"脱敏自查：MAC 0 / IP 0 / 黑名单 0 命中（规范文件除外）"）。

## 7. 违规处理

- **提交前发现** → 按 §4 重扫后重新提交；
- **PR review 发现** → 标记 `[sensitive-info]`，要求修订后再合入；
- **已合入历史** → 视为安全事故，按"改写历史 + 轮换凭据"处理：能改写的提交改写（`filter-branch`/`filter-repo`），无法改动时同步确认相关账号/会话已无实际可用性；严禁用"后续修复提交"掩盖历史中的敏感值；
- **多次/恶意** → 永久限制贡献，必要时向平台报告。

---

## 8. 修订与维护

- 占位符清单（§3.2）与黑名单（§5.2）由仓库维护者维护，贡献者可通过 PR 提议扩展；
- 扩展黑名单时必须附"该词为何敏感"的一行说明；
- 本文档自身是白名单语境的唯一例外，其余任何文件不得复制本文档中的词条/正则作为"可接受内容"。

## 9. 私密侧材料类别速查（贡献者自查备忘）

> 下列**材料类别**只允许存在于本地私密目录，禁止以任何形态（含改写后）进入开源仓。
> 本节仅列类别与红线理由，**不列出真实文件名、路径或标识**（真实标识本身即违规）；
> 类别描述沿用 §2 红线与 §5.2 黑名单，供贡献者在整理 PR 前快速归类自查。

| # | 私密侧材料类别 | 红线理由（对应 §2 / §5.2） |
|---|---|---|
| 1 | 认证门户前端逆向产物：JS 主包 / 异步分块 / 样式 / 预加载清单 | 通常内嵌接口面、加密封装模块、调试残留、品牌信息（红线 3/5） |
| 2 | 解密后的门户配置 JSON、解密工具 / API 客户端脚本 | 含品牌文案、接口参数、AES/密钥常量、账号相关字段（红线 4/5） |
| 3 | 门户接口面清单（路由→功能→参数映射表） | 指向特定服务商实现，属红线 3；含真实主机地址形态（红线 2） |
| 4 | 漏洞验证记录：接口枚举 / 越权 / 伪加密实测表、攻击链推演、利用链脚本 | 含真实账号、凭据、会话 ID、设备标识与漏洞细节（红线 3/5/6） |
| 5 | 实测日志 / 汇总报告（含真实会话、设备、账号、精确速率、SSID） | 含真实 MAC/IP/账号/精确值（红线 1/2/5/7） |
| 6 | 端口扫描 / 网络拓扑探测结果（含真实网段、网关、NAT 出口） | 含真实 IP 与设备标识（红线 1/2/6） |
| 7 | 代理订阅文件与订阅源：订阅 YAML、还原脚本、节点清单 | 订阅 / 节点信息（红线 4、§5.2 黑名单） |
| 8 | 白名单快照、nvram 导出、VM 配置与磁盘镜像 | 含真实 MAC / 网络标识 / 他人设备信息（红线 1/6） |
| 9 | 内部运维备忘：本机脚本资产清单、密钥文件、绝对路径、任务计划 | 含密钥路径与内部路径（红线 5/8） |

**归类即弃用**：任何落在上表的文件，即使"看起来只有一句结论可以引用"，也不得整段改写进开源仓；
如需向开源侧贡献其中某项**方法论**，只能按 §3 占位符 + §4 自查流程重新撰写，且不得引用原文件名。

> 示例（正确姿势）：某接口"无鉴权枚举"结论可在原理文档中以**通用安全风险**表述（"查询类接口通常不校验归属"），但不得出现该接口的真实调用形态、真实返回样例或厂商词条。
